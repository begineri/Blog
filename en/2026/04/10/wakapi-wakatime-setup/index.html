Wakapi & WakaTime Setup: Tracking Coding Time

Wang
2026-04-10
coding

Background

I was looking for a tool to automatically track my coding time, so I came across WakaTime.

WakaTime supports a wide range of IDEs. For more details, visit: https://wakatime.com/plugins

However, much of WakaTime’s content requires an additional fee; for example, free users can only view their coding time for the past 7 days, which is quite inconvenient.

Therefore, using Wakapi to store data locally is a great choice.
I’ve been using WakaTime all along, and now I can import my data with a single click. Here’s what my dashboard looks like now:

It’s very clear—you can click on each project to view its specific time breakdown. For example, for last semester’s CO (you can see that I spent over 6 hours writing P5 code and documentation; clicking further reveals even more detailed information):
