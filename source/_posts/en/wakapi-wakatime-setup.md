## Background
I was looking for a tool to automatically track my coding time, so I came across WakaTime.

WakaTime supports a wide range of IDEs. For more details, visit: https://wakatime.com/plugins

However, much of WakaTime’s content requires an additional fee; for example, free users can only view their coding time for the past 7 days, which is quite inconvenient.

---
Therefore, using Wakapi to store data locally is a great choice.

## Deployment Reference Process
Here is my deployment plan. For more information, see:
Wakapi on GitHub：[https://wakatime.com](https://github.com/muety/wakapi)
WakaTime：[https://wakatime.com](https://wakatime.com)

### Deploying Wakapi
I use Docker:
1. One-Click Backend Deployment with Docker

```bash
# Create a persistent volume
$ docker volume create wakapi-data

$ SALT="$(cat /dev/urandom | LC_ALL=C tr -dc 'a-zA-Z0-9' | fold -w ${1:-32} | head -n 1)"

# Run the container
$ docker run -d \
  --init \
  -p 3000:3000 \
  -e "WAKAPI_PASSWORD_SALT=$SALT" \
  -v wakapi-data:/data \
  --name wakapi \
  --restart unless-stopped \
  ghcr.io/muety/wakapi:latest
```

2. Open `http://localhost:3000/login` locally and register an account to access the API.

3. Data linked to the IDE
At this point, you can simply follow the instructions on the webpage. For reference, see:
   - If you’ve already been using WakaTime, you can import your data directly (my choice):
     - As shown in the image, simply paste your WakaTime API key into the settings, then click `Import Data` to import historical data.
     ![alt text](/images/Wakapi/导入.png)
     - It’s working fine now, so I’ve decided to keep the original WakaTime configuration. WakaTime is still running on my local machine, and I’ll only sync when necessary (since switching to wakapi might introduce unknown bugs that can’t be resolved).
   - Or configure it from scratch (see the steps on the website):
       1. Download and install the required IDE plugin from https://wakatime.com/plugins
       2. Modify content `~/.wakatime.cfg` to ():
       ```
       [settings]
        api_url = https://wakapi.dev/api
        api_key = <put your api key here>
       ```
       3. Refresh, done!
